# Otus Diplom

Тема проекта: создание Telegram-бота для организации отчетности сотрудников перед lead.

## Роли пользователей бота

В Telegram-боте будут использоваться следующие роли.

### Сотрудник

Сотрудник - основной пользователь бота, который отправляет отчетность о своей работе.

Функции сотрудника:

- отправка ежедневного отчета;
- указание выполненных задач;
- указание текущих проблем или блокеров;
- просмотр своего последнего отправленного отчета;
- просмотр списка назначенных задач;
- перевод задачи в статус "в работе";
- закрытие задачи с обязательным комментарием;
- получение уведомления о назначенной задаче;
- получение уведомления о скором окончании срока задачи;
- получение напоминаний о необходимости отправить отчет.

### Lead

Lead - пользователь, который контролирует отчетность сотрудников и просматривает результаты их работы.

Функции lead:

- просмотр отчетов сотрудников;
- просмотр отчета конкретного сотрудника;
- назначение задач сотрудникам;
- указание срока выполнения задачи;
- просмотр списка задач конкретного сотрудника;
- просмотр статусов задач сотрудника;
- просмотр списка сотрудников;
- проверка, кто отправил отчет за выбранный день;
- проверка, кто еще не отправил отчет;
- получение краткой сводки по отчетам команды;
- получение списка задач всей группы.

### Администратор

Администратор - пользователь, который помогает настраивать работу бота.

Функции администратора:

- добавление сотрудников в систему;
- назначение роли lead;
- удаление пользователей из системы;
- просмотр списка зарегистрированных пользователей;
- настройка базовых параметров бота;
- настройка времени уведомления до окончания срока задачи.

## Статусы задач

В боте используются простые статусы задач:

- открыто - задача создана и назначена сотруднику;
- в работе - сотрудник начал выполнять задачу;
- закрыто - сотрудник завершил задачу и оставил комментарий.

Новая задача всегда создается со статусом "открыто".

## MVP проекта

Изначальный MVP, который был запролирован


### Роли MVP

- сотрудник;
- администратор;
- lead.


### Функции MVP

Функции сотрудника:

- отправить ежедневный отчет;
- добавить выполненную задачу в отчет;
- указать проблему или блокер;
- посмотреть свои назначенные задачи;
- перевести задачу в работу;
- закрыть задачу с комментарием.

Функции lead:

- посмотреть отчеты сотрудников;
- посмотреть отчет конкретного сотрудника;
- назначить задачу сотруднику со сроком;
- посмотреть задачи конкретного сотрудника;
- посмотреть задачи всей группы.

Функция Администратора:
- наздачение Lead;
- настройка уведомления;
- добавление пользователя.

### Запросы MVP (на данный момент часть запросов уже изменена и реализована с использование Telegram-бота)

Запросы сотрудника:

- `/report` - отправить ежедневный отчет;
- `/task` - добавить выполненную задачу;
- `/block` - указать проблему или блокер;
- `/my_tasks` - посмотреть свои задачи;
- `/start_task 1` - перевести задачу в работу;
- `/close_task 1` - закрыть задачу с комментарием.

Запросы lead:

- `/reports` - посмотреть отчеты сотрудников за сегодня;
- `/employee_report Иван Иванов` - посмотреть отчет конкретного сотрудника;
- `/assign_task Иван Иванов | Подготовить отчет | 20.05.2026` - назначить задачу сотруднику;
- `/employee_tasks Иван Иванов` - посмотреть задачи конкретного сотрудника;
- `/team_tasks` - посмотреть задачи всей группы.

Запросы Администратор:

- `/add_employee` - добавить сотрудника по username Telegram;
- `/set_lead имя` - назначить пользователю роль lead;
- `/remove_user имя` - удалить пользователя;
- `/users` - посмотреть всех зарегистрированных пользователей
- `/settings` - посмотреть настройки бота;
- `/set_task_deadline_reminder часы` - настроить уведомление до дедлайна задачи.

## Архитектура реализации

Проект разделен на слои.

### Core

Папка `Core` содержит доменные сущности, интерфейсы репозиториев и бизнес-сервисы.

Основные части:

- `Core/Entities` - сущности и enum-статусы;
- `Core/DataAccess` - интерфейсы репозиториев
- `Core/Services` - интерфейсы и реализации бизнес-сервисов

### Infrastructure

Папка `Infrastructure` содержит реализации хранения данных.

### TelegramBot

Папка `TelegramBot` содержит интерфейс отправки сообщений и заготовку Telegram-слоя.
 - `TelegramBot/Scenarios` - расписаны все сценариии работы бота.


## Запросы и ответы бота

Ниже описаны основные запросы пользователя и ответы Telegram-бота для функций из раздела с ролями.

### Сотрудник

#### Отправка ежедневного отчета

Запрос:

```text
/report
```

Ответ:

```text
Отправить отчет?
```
Запрос:

```text
Да
```

Бот отвечает если "Да":

```text
Отчет отправлен.
```
В базе данных ставится пометка, что сотрудник за сегодня сдал отчет. 

Бот отвечает если "Нет":

После завершения:

```text
Отчет не отправлен.
```

#### Указание выполненных задач

Запрос:

```text
/task
```

Ответ:

```text
Введите выполненную задачу.
```

Запрос:

```text
Сделал задачу по авторизации, исправил ошибку в форме отчета.
```

Ответ:

```text
Выполненные задачи добавлены в отчет.
```

#### Указание проблем или блокеров

Запрос:

```text
/block
```

Ответ:
```text
Какая проблема возникла?
```

Запрос
```text
Проблема с доступом.
```

Ответ:

```text
Проблемы добавлены в отчет.
```

#### Просмотр последнего отчета

Запрос:

```text
/my_last_report
```

Ответ:

```text
Ваш последний отчет:
Дата: 16.05.2026
Выполнено: сделал задачу по авторизации.
Проблемы: нет.
```

#### Получение напоминания

Запрос выполняется ботом автоматически.

Ответ:

```text
Напоминание: не забудьте отправить ежедневный отчет.
```

#### Просмотр списка назначенных задач

Запрос:

```text
/my_tasks
```

Ответ:

```text
Ваши задачи:
1. Подготовить отчет по проекту
Статус: открыто
Срок: 20.05.2026

2. Проверить форму отправки отчета
Статус: в работе
Срок: 18.05.2026
```

#### Перевод задачи в работу

Запрос:

```text
/start_task 1
```

Ответ:

```text
Задача "Подготовить отчет по проекту" переведена в статус "в работе".
```

#### Закрытие задачи

Запрос:

```text
/close_task 1
```

Ответ:

```text
Введите комментарий по выполненной задаче.
```

После ввода комментария:

```text
Задача закрыта. Комментарий сохранен.
```

Если сотрудник не оставил комментарий:

```text
Для закрытия задачи необходимо оставить комментарий.
```

#### Уведомление о назначенной задаче

Запрос выполняется ботом автоматически после назначения задачи lead.

Ответ:

```text
Вам назначена новая задача:
Подготовить отчет по проекту
Срок: 20.05.2026
Статус: открыто
```

#### Уведомление о скором окончании срока задачи

Запрос выполняется ботом автоматически за время, которое настроил администратор.

Ответ:

```text
Напоминание: срок задачи "Подготовить отчет по проекту" заканчивается 20.05.2026.
```
